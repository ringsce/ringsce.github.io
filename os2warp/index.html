OS/2 Warp 4.52 for ARM64

QEMU virt (Cortex-A72) and Raspberry Pi 3/3+

A bare-metal OS/2-style operating system with a PL011 UART driver, a readline-style DOS shell, a QuickBASIC-compatible interpreter, and a full FAT32/VFS stack backed by either a RAM disk or QEMU virtio-blk.

Boots on QEMU virt | Boots on Raspberry Pi 3+ | Active Development

Highlights

Readline DOS Shell

Arrow keys, Home/End, insert mode, Ctrl-A/E, Ctrl-C, Ctrl-D, Ctrl-L, and a 16-entry command history.

QuickBASIC Interpreter

A QuickBASIC 4.5-compatible interpreter (IF/SELECT CASE/FOR/WHILE/DO LOOP, GOSUB, arrays, string functions) launched with the basic command.

FAT32 / VFS Stack

cli_fs -> vfs -> fat32 -> blkdev layers, with ramdisk and QEMU virtio-blk drivers (SD card support planned for Raspberry Pi).

OS/2 DosCall API

doscalls.c stubs out the OS/2 DosCall API surface for shell and BASIC programs to build on.

Platform Support

QEMU virt (development)

  • CPU: Cortex-A72
  • RAM: configurable (2GB default)
  • UART: PL011 @ 0x09000000
  • Load address: 0x40000000
  • Output: os2warp.img

Raspberry Pi 3+ (hardware)

  • CPU: Cortex-A53 (64-bit)
  • RAM: 1GB
  • UART: PL011 @ 0x3F201000
  • Load address: 0x80000
  • Output: kernel8.img

Build & Run (QEMU)

git clone https://github.com/ringsce/os24arm.git
cd os24arm

cmake -B build -G Ninja
cmake --build build

# Boot (serial console, no window)
cmake --build build --target run

QuickBASIC Interpreter

Type basic at the shell to launch it; BYE, QUIT, or SYSTEM returns to the shell.

10 PRINT "Hello from OS/2 BASIC!"
20 FOR I = 1 TO 10
30   PRINT I * I
40 NEXT I
50 END
RUN
