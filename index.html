Kayte Lang

A modern, cross-platform programming language

Compiles to bytecode that runs on the Kayte Virtual Machine (KVM), with native ARM64 compilation, a declarative UI framework, and JVM interoperability.

KayteIDE

A lightweight, cross-platform IDE for Visual Basic code

Built with Qt 6 and C++17: file management, VB syntax highlighting, and a file properties dialog, with Build/Run/Clean/Debug actions as placeholders for a fuller IDE experience.

Open KayteIDE →

OS/2 Warp 4.52 (ARM64 Edition)

A bare-metal ARM64 revival of OS/2 Warp

A bare-metal OS/2-style OS in C11 + AArch64 assembly for QEMU virt and Raspberry Pi 3+, with a QuickBASIC interpreter and a FAT32/VFS stack. There is no in-browser simulator yet.
