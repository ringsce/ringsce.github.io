KayteIDE

A lightweight, cross-platform IDE for Visual Basic code

KayteIDE provides core functionality for editing, saving, and managing Visual Basic (VB) code, enhanced with syntax highlighting for improved readability.

Get StartedView on GitHub

Features

File Management

Open existing Visual Basic source files, save changes, and Save As to a new location.

Syntax Highlighting

Basic syntax highlighting for VB keywords, data types, functions, operators, comments, strings, numbers, and preprocessor directives, with colors inspired by common IDE themes.

File Properties Dialog

View detailed information about the currently open file: general details (size, dates), permissions, and suggested applications.

Project Actions

Placeholder

"Build," "Run," "Clean," and "Debug" actions are included as placeholders, signaling future expansion into a more comprehensive IDE experience.

Supported Platforms

macOS (Intel and Apple Silicon - Universal Binary support)

Linux (x86_64 and other architectures where Qt 6 is available)

Getting Started

Prerequisites

  • Git - for cloning the repository
  • CMake - version 3.16 or higher
  • A C++17-compliant compiler (GCC, Clang, or MSVC)
  • Qt 6 development libraries

Build & Run

git clone https://github.com/ringsce/kayteide.git
cd kayteide

mkdir build
cd build
cmake ..
cmake --build . --parallel

# Run it
./bin/KayteIDE

Usage

  • Open File: File > Open (or the toolbar button) to load a .vb / .bas file into the editor.
  • Save File: File > Save to save changes; new files prompt for a save location.
  • Save As: File > Save As to save the current content to a new file.
  • File Properties: File > Properties... for detailed info about the current file.
  • Project Actions: Build / Run / Clean / Debug currently show placeholder messages.
